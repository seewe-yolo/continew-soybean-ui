# 文件管理原版分析与改造范围

参照官方 [continew-admin-ui dev](https://github.com/continew-org/continew-admin-ui/tree/289fdccc3fe4246c2ab21a2028b0c8f135d59c70/src/views/system/file)，版本 4.2.0，与当前后端 4.2.0-SNAPSHOT 对应。分析先于实现。

| 区域     | 原版行为                                                                          | 当前改造方案                                                                   |
| -------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 页面     | 220px 分类列（含 14px gutter，实际内容 206px）、统计环图、14px 间隔，根目录面包屑 | 保留 Soybean 外壳，用 Naive UI 和局部样式复现原版文件工作区                    |
| 分类     | 全部、图片、文档、视频、音频、其他                                                | 全部不传 type，以 / 查询目录；分类查询不传 parentPath                          |
| 内容     | 默认网格，列表切换，30 条分页，按类型及修改时间排序                               | 共用查询与选中状态，文件图标复用原版 SVG 资源                                  |
| 操作     | 上传、新建文件夹、查询、批量操作、回收站；右键重命名、详情、下载、删除            | 保持对应权限；删除和永久删除确认；上传和删除刷新统计                           |
| 上传     | 共用“文件上传”弹窗，最大宽 1350px，虚线框内 700px 任务表                          | 支持文件多选、文件夹和拖放；任务分页及开始、暂停、继续、重试、取消、删除、清空 |
| 上传策略 | 后端默认存储配置决定普通/分片，初始化返回分片大小与已传序号                       | 不写死阈值，普通上传查询服务端进度，分片保留会话与成功分片，检查 success       |
| 回收站   | 最大宽 1100px，无底部按钮，查询、重置、清空、刷新，逐行还原/删除                  | 使用 /system/file/recycle 系列现有接口                                         |
| 其他弹窗 | 重命名 450px；详情 320px；新建目录；图片、Office、视频和音频预览                  | 使用现有弹窗体系调整尺寸；复用成熟预览库，不向第三方上传文档                   |

原版单文件、批量与分片并不是三个独立弹窗，而是同一上传任务表中的不同任务。普通上传暂停后继续会重启该文件上传；分片暂停后保留已完成分片。关闭上传弹窗前确认未完成任务并清理请求/会话。

按钮、弹窗、输入框、表格、分页及确认提示统一复用当前项目的 Naive UI 和现有 ButtonIcon，继承全局主题。原版仅作为布局和业务流程参考，不覆盖组件库的颜色、尺寸、圆角、弹窗标题或内边距。图片预览使用 NImageGroup / NImage，音频窗口使用 NModal；图标通过现有 ButtonIcon 的插槽使用本地打包的 Lucide 资源。

后端支持文件列表、统计、目录创建/大小计算、重命名、软删除、回收站、默认上传配置、上传进度和 multipart init/part/complete/cancel；不新增数据库变更或后端接口。详情使用列表 FileResp（原版也如此），不虚构 GET 详情接口。

原版 PPT/PPTX 虽触发 Office 弹窗，但没有对应渲染器；这里显示可下载/打开的兜底状态，避免空白预览。DOC 仅在实际渲染支持时显示，否则同样提供错误和下载入口。

验证使用模拟接口隔离数据，覆盖布局、目录与分类、回收站权限、上传策略、失败/重试/暂停/继续/取消和关闭清理。不会在真实数据库中执行测试删除。

工具限制：codebase-memory MCP 返回 Transport closed，代码理解与调用方核对使用源码和 rg 回退；frontend-spec、admin-ui-design 未安装，按当前项目规范和原版源码实现。不能声明图谱覆盖完整或真实后端联调完成。

原版 SVG 文件资源使用 Apache-2.0 许可证，来源和许可证随资源保留。
